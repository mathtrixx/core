# BHmcMods

A modern modding toolkit and utility set for Minecraft using Skript.

## Overview

Core is designed to function as a fun toolkit for users to scare/prank their friends. It provides a clean, efficient, and easy-to-use experience for users who want to break the silence through fun, more useless commands or kicking/banning users through administrative commands.

Whether you are a casual user or an advanced developer, Core aims to make the usual basic/boring server more interesting and vibrant.

## Features

- Easy setup and installation
- Lightweight and efficient design
- Compatible with Java/Bedrock
- Customizable options for different use cases
- Built for reliability and maintainability
- Open for community contributions
